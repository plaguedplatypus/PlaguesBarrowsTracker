# Barrows Tunnel Tracker

An [Alt1 Toolkit](https://runeapps.org/alt1) helper for remembering which Barrows mound leads to the final encounter.

## Features

- Select the tunnel mound manually from the Barrows map.
- Keep Verac and Akrisae as separate selectors while they share a crypt.
- Watch the **Brothers slain** panel and mark defeated brothers automatically.
- Infer the tunnel mound when only one eligible brother remains.
- Reset the selection after the completed-run chat message is detected.
- Choose which visible chat window to monitor when multiple chat windows are open.
- Optionally show Akrisae and Linza after completing their respective quests.
- Display slain status for defeated brothers; Linza is display-only and cannot be selected as a tunnel candidate.
- Open a compact visual reference for Barrows tunnel puzzle solutions.

## Requirements

- RuneScape with the Alt1 Toolkit installed.
- Alt1's **View screen** permission enabled for this app.

## Usage

Click the mound that leads underground. The selection is saved locally and can be cleared with the reset button. When automatic detection is active, the app reads the Brothers slain panel and completed-run chat message to update the map for you.

If more than one RuneScape chat window is visible, open **Settings** and choose the chat window to monitor. The choice is remembered locally. Use **Find Chat** after moving or changing chat windows.

The optional Akrisae and Linza toggles are available in **Settings**. Akrisae requires *Ritual of the Mahjarrat* and Linza requires *Kindred Spirits*.

## Privacy

The app processes the visible RuneScape interface locally through Alt1. It does not upload screenshots, chat, or player data.
